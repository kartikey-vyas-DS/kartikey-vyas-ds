## Featured Work

### Jaquar Price Pulse

[Repository](https://github.com/kartikey-vyas-DS/jaquar-price-pulse) | [Live Dashboard](https://kartikey-vyas-ds.github.io/jaquar-price-pulse/dashboard/)

Serverless data engineering project for tracking Jaquar faucet price movement.

- Built an AWS pipeline using Lambda, S3, RDS/PostgreSQL, Step Functions, EventBridge, API Gateway, Python, SQL, and dbt-style transformation logic.
- Designed daily snapshot ingestion, historical price modeling, change detection, alert APIs, and a public dashboard to flag SKU-level MRP movement.

### Marketplace Operations and Internal Tools

Built and maintained systems for a B2B construction-material marketplace, including:

- Lead management CRM with lead capture, appointments, field visits, revisits, activity logs, status tracking, and GSTIN/PAN/mobile-based duplicate matching.
- Quote Builder for reusable product templates, SKU variations, GST/HSN/pricing fields, margins, discounts, and Excel quotation exports.
- Price comparison dashboard for Bengaluru quick-commerce building-material platforms, using Google Apps Script, JavaScript, and HTML to consolidate competitor prices and surface SKU-level gaps.
- Catalogue workflows supporting 350,000+ SKUs, vendor onboarding, listing quality, and quick-commerce product readiness.
